## Identidad utilizada en la aplicación

`logo-light.svg` y `logo-dark.svg` reconstruyen el identificador IRONMAN Valdivia Chile en geometría vectorial, sin la marca del patrocinador. Las dos variantes comparten los mismos trazados; solamente cambia el color (tinta #102330 o blanco #ffffff). No contienen fondos ni dependen de fuentes externas. El encabezado selecciona la variante correspondiente al modo claro u oscuro.

El PNG original se conserva como referencia y ya no se presenta en la interfaz. La herramienta de generación de imágenes no produjo un resultado; los SVG se construyeron como recursos vectoriales nativos del proyecto.
